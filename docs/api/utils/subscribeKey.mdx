# `subscribeKey`

To subscribe to a primitive value in proxy state, consider `subscribeKey`.

```js
import { subscribeKey } from 'valtio/utils'

const state = proxy({ count: 0, text: 'hello' })
subscribeKey(state, 'count', (v) =>
  console.log('state.count has changed to', v),
)
```

For data properties, `subscribeKey` is a convenience wrapper around the
key-based `subscribe` API:

```js
subscribe(state, callback, { keys: ['count'] })
```

For getter properties, `subscribeKey` uses a whole-proxy subscription so that
changes to the getter's dependencies can update the subscribed value.

The callback runs only when `state[key]` changes according to `Object.is`.
For an object-valued key, descendant mutations do not change that reference.
Use `subscribe(state, callback, { keys: [key] })` to observe those mutations too.
